# 매뉴얼 (서논술형 시스템 RAG 근거)

이 폴더에 **서논술형 시스템 매뉴얼**을 `.md` / `.markdown` / `.txt` 로 넣으면,
봇이 1차 응대 초안을 만들 때 **제품 사실의 1차 근거**로 함께 참조합니다.

- PDF/한글(hwp) 등은 먼저 텍스트/마크다운으로 변환해 넣어 주세요.
- 여러 파일을 넣으면 파일명 순서로 합쳐져 참조됩니다(총 길이 상한 있음).
- `MANUALS_DIR` 환경 변수로 다른 폴더를 지정할 수 있습니다.
- 이 폴더가 비어 있으면 매뉴얼 참조 기능은 자동으로 꺼집니다(기존 동작 불변).
